### Featured Projects & Technical Case Studies

1. **BLDC Motor Drive System & EV Powertrain Simulation** (`bldc.html`)
   * Co-simulation combining a 3-phase DC-AC PWM inverter in LTspice with 2D electromagnetic Finite Element Analysis (FEA) in ANSYS Maxwell 2D.
   * Features detailed magnetic flux density contour maps (1721.73 mT peak), steady-state torque graphs (~4.4 N·m), and 120° conduction trapezoidal phase current analysis.

2. **Clinical ECG Signal Processing & FIR Filter Design** (`ecg.html`)
   * Characterisation and refinement of clinical ECG data from the PhysioNet MIT-BIH Arrhythmia Database.
   * Features spectrum analysis, Hamming window parameter selection, and a 115-tap FIR band-pass filter design (0.5 Hz - 40 Hz) eliminating baseline wander and muscle noise.

3. **Synchronous Buck Converter — Circuit & PCB Design** (`buck.html`)
   * 4-layer KiCad PCB design converting 12V to 5V at 5A continuous load current, switching at 300kHz.
   * Complete thermal management calculations, component placement, DFM layout constraints, and parasitic inductance minimisation.

4. **ML-Based Component Health Monitoring for Space Systems** (`prognostics.html`)
   * Object-oriented Python pipeline evaluating NASA’s C-MAPSS turbofan dataset.
   * Implemented Random Forest regression for Remaining Useful Life (RUL) prediction, failure window classification (96.21% accuracy), and unsupervised K-Means lifecycle clustering.

5. **Microprocessor System Design & FPGA Integration** (`microprocessor.html`)
   * RTL design in SystemVerilog integrated onto an FPGA board.
   * Custom ALU, Program Counter, register file architecture, and assembly execution verified via VGA display output.

6. **180-Degree Ultrasonic Radar System** (`radar.html`)
   * Embedded hardware interfacing using an Arduino microcontroller and HC-SR04 ultrasonic distance sensor.
   * Software offset calibration from ±10 cm to ±6 cm over a 180° sweep.
