Microprocessor System Design - FPGA Integration Project

Custom processor core modelled, verified, and mapped onto FPGA fabric using modular hardware description logic.

1. Project Overview & RTL Design

Modern digital designs rely heavily on modelling custom processing cores inside FPGA architectures. In this project, I integrated a custom microprocessor system on an FPGA fabric using SystemVerilog. I designed and combined the core logic structures needed to build a functional 8-bit instruction execution unit.

2. Modelling Core Processor Modules

The internal logic modules were written inside a hierarchical SystemVerilog design framework. Key components designed include:

  • Arithmetic Logic Unit (ALU): Modelled operations-mapped logic to execute arithmetic additions, subtractions, and bitwise boolean logic (AND, OR).
  • Program Counter (PC): Programmed the fetch clock cycle routing that controls instruction flow.
  • General Registers: Built internal register files (R0, R1) and the Accumulator (ACC) to facilitate pipeline variables storage.

3. Hardware Verification & Peripherals Mapping

To verify instruction execution under timing constraints, I mapped physical hardware peripherals on the FPGA board to internal logical nodes:

  • Switch Interaction: Used slide switch arrays to load register inputs manually during hardware test sequences.
  • LED Indicators: Mapped internal control flags and register outputs to board LEDs to verify correct register write-enables.
  • VGA Video Controller: Programmed a VGA controller interface to output execution data onto an external monitor screen.

Implementing and testing a basic assembly-level instruction set through switch and LED interactions resulted in successful execution, producing visual data output directly on a VGA display.

4. Outcomes & Takeaways

The project successfully verified register-transfer-level (RTL) operations. Through this FPGA project, I gained practical experience in hardware design, modular SystemVerilog structure, and diagnostic verification.
