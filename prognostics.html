ML-Based Component Health monitoring - Space System

Object-oriented predictive modelling pipeline designed to predict component failure timelines in space systems.

1. Project Background & Motivation

Space platforms demand predictive failure detection due to zero physical maintenance access post-launch. Under condition-based maintenance strategies, hardware sensors must be analysed in real time to diagnose degradation patterns.

I designed an object-oriented Python system for ML-based component health prognostics. The system targets predictive failure detection in space assets, validated on NASA’s C-MAPSS turbofan engine degradation dataset as a proof of concept.

2. Machine Learning Pipeline Architecture

The project builds a multi-stage machine learning pipeline to predict continuous component failure timelines (regression) and detect early-stage degradation windows (classification) across multidimensional sensor data:

  • Feature Engineering: Mapped and standardised 21 sensor channels and 3 operational setting variables to normalize across varying pressure ratios and fan speeds.
  • Pipeline Modularization: Built using object-oriented Python modules, dividing processes into data loader class files, estimator models, and CV validation frameworks.

3. Hyperparameter Optimisation & Metrics

To ensure high prediction precision, I trained Random Forest regression models, executing cross-validation and hyperparameter tuning:

  • Grid Search CV: Tuned hyperparameters (such as decision tree depth, leaf configuration sizes, and estimator quantities) via grid search to prevent overfitting.
  • MSE Reduction: Hyperparameter tuning cut overall failure prediction error by 15% compared to base models.
  • Early Warning Accuracy: Boosted early degradation stage detection accuracy by 11%, giving engineering operators longer lead times before failure boundaries are reached.

4. Remaining Useful Life (RUL) Regression

The aim of this part of the study is to predict the exact number of Remaining Useful Life (RUL) cycles for a jet engine based on sensor readings. We chose a Random Forest Regressor for this task because it handles the non-linear relationship between sensor degradation and time very well. By using an ensemble of decision trees, the model can provide a stable prediction of engine life which is vital for maintenance planning in aviation.

5. Failure Window Classification

By defining a failure window of 30 cycles, we construct a binary classification model to identify near-failure states. The model achieved a total accuracy of 96.21% (0.9621) using a tuned Random Forest (n_estimators=100, Gini impurity, random_state=42). The confusion matrix confirms the system correctly identified 3,483 healthy states and 484 failure states, with only 60 false positives and 100 false negatives. This provides a highly reliable early alert system for engineering maintenance.

6. Unsupervised Lifecycle Clustering

To explore natural lifecycle groupings without using pre-defined labels, we applied K-Means clustering to partition the multidimensional sensor readings (such as pressure, temperature, and vibration patterns). The model successfully identified three distinct clusters corresponding to the healthy, transitioning, and critical phases of engine wear. Centroid starting positions were optimised using the k-means++ initialisation method with a random_state of 42. While K-Means assumes spherical cluster boundaries, this unsupervised analysis provides objective mathematical validation of the degradation stages used in our supervised models.

7. Outcomes

The object-oriented pipeline successfully forecasts Remaining Useful Life (RUL) limits, classifies critical maintenance windows, and models wear phases via unsupervised clustering. Through this project, I developed proficiency in scientific Python libraries (scikit-learn, pandas, numpy) and prognostic telemetry systems.
